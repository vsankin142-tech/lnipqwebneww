# ПРИЗМА — цифровая студия

Одностраничный сайт-витрина творческой студии: тёмная неоновая тема,
Unbounded + Manrope, куча анимаций и дизайнерских деталей.

## Запуск

Сайт статичный — достаточно любого статического сервера:

```bash
# вариант 1
python3 -m http.server 8080 --bind 0.0.0.0

# вариант 2
npx serve .
```

Открыть: http://localhost:8080

## Что внутри

- **Прелоадер** — счётчик 000→100, построчное появление логотипа, шторки
- **Кастомный курсор** — точка + инерционное кольцо, режим «Смотреть» на кейсах
- **Лерп-скролл** — плавное «тягучее» движение страницы
- **Частицы на canvas** — поле с соединяющими линиями, реагирует на мышь
- **Аврора-фоны** — дрейфующие размытые градиентные пятна
- **Разбивка заголовка** на слова с mask-reveal (stagger)
- **Бегущие строки** (marquee) в две линии, контурный текст
- **Scroll-reveal** через IntersectionObserver (fade-up + stagger)
- **Счётчики** цифр с easeOutExpo
- **Tilt-карточки** с 3D-наклоном и бликом, following mouse
- **Мagnetic-кнопки** — притягиваются к курсору
- **Параллакс** декоративных элементов (`data-speed`)
- **Слайдер отзывов** с автопрокруткой, точками и стрелками
- **Навигация** — скрывается при скролле вниз, blur-подложка, мобильное меню
  с clip-path-анимацией и stagger-ссылками
- **Прогресс-бар** чтения, кнопка «наверх», зернистость (grain/noise overlay)
- **Easter egg**: три раза нажмите `P` 🙂
- Уважает `prefers-reduced-motion` и тач-устройства (лерп-скролл и курсор
  отключаются)
